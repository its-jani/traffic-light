# Traffic Light Slash Command (/traffic)

Controls the floating desktop traffic light widget.

## Commands:
- `/traffic on` - Register session and activate Green light
- `/traffic yellow [msg]` - Set light to Yellow (Thinking / Generating)
- `/traffic green [msg]` - Set light to Green (Done / Ready)
- `/traffic red [msg]` - Set light to Red (Needs Input / Error)
- `/traffic off` - Turn traffic light off / dismiss session
