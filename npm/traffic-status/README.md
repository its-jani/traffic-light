# traffic-status

Minimalist floating desktop traffic status widget for AI coding agents (**Claude Code**, **OpenCode**).

## Installation

```bash
npm i -g traffic-status
traffic-status install --global
```

Or via npx:

```bash
npx traffic-status install --global
```
